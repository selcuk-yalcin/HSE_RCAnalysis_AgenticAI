## 💡 Key Insights

### Why DSPy Over Manual Prompting?

```python
# V2.5 (Manual)
prompt = f"""
KRİTİK KURALLAR:
A) WHY-1 ÖZEL KURAL
B) SADECE RAPORDA YAZANLARA DAYAN
C) ... 100+ more lines ...
"""

# V3.1 (DSPy)
class WhyQuestion(dspy.Signature):
    previous_answer = dspy.InputField(desc="...")
    question = dspy.OutputField(desc="...")
# That's it! DSPy handles the prompt generation

# Benefits:
# - Shorter, clearer code
# - Automatically optimizable (MIPRO)
# - Type-safe
# - Easier to test
```

### Semantic vs Syntactic Similarity

```python
# V2.5: Syntactic (Jaccard)
text1 = "eğitim verilmemiş"
text2 = "eğitim eksikti"
similarity = jaccard(text1, text2)  # Low (different words)

# V3.1: Semantic (DSPy verification)
# "Aynı konsepti farklı şekilde yan cümle ile ifade et"
# → Model cevaplarını otomatik farklılaştırır
```
